# Key Concepts

FK 输入关节角 q、输出位置 p=f(q)；位置 IK 给定目标 p_target，寻找合适的 q。
位置误差 e=p_target-f(q)，目标与当前位置都用世界 xy 坐标、单位 m。
利用当前姿态的 J 求解 J*δq=e，得到完整的局部线性修正 δq（rad），
再按 q_new=q+α*δq 更新，其中 α 为无量纲步长比例，本课取 0.5。
α 不是物理时间步长，δq 不是力矩。新 q 是候选姿态，不表示机器人瞬间物理运动到那里。
本例使用可逆 2×2 J，直接解两条线性方程；不把这个方法泛化为所有 Jacobian 都可逆。

Jacobian 只作局部近似：必须用 FK 重算新位置和误差，不能仅凭 J*δq=e 宣称到达。
较小 α 缩短单次修正，但不保证任意情况下收敛。接近奇异时须注意增量可能很大。
成功停止：新位置误差的欧氏长度 ||e|| 小于选定容差（本课 ε_pos=1e-4 m，即 0.1 mm）。
迭代次数上限是终止保护，不是成功条件；后续 S5.3/S5.4 才实现循环、关节限制和失败测试。
来源：[Modern Robotics 数值 IK](https://modernrobotics.northwestern.edu/nu-gm-book-resource/6-2-numerical-inverse-kinematics-part-1-of-2/)。

## S5.3 有上限的迭代与关节限制（2026-09-29，已完成）

沿用同一初始姿态、目标、alpha=0.5 和 1e-4 m 容差，拟最多接受 20 次更新。
每个当前 q：重算 FK → 记录真实误差 → 检查成功 → 检查更新次数上限 →
重算当前 Jacobian → 求增量 → 检查候选关节角 → 接受更新。
第 20 次更新后的姿态也必须经过 FK 与成功检查；初态记录为第 0 次，最多 21 条记录。
Jacobian 随姿态改变，不能在整个循环固定使用初始矩阵。

本课人为设置两关节范围均为 [-π,π] rad，仅作教学限制，不代表 UR5e 规格。
候选角越界时采用简单策略：拒绝该次更新并停止，保留最后合法 q。
这只说明本次求解终止，不能据此证明目标不可达；不自动裁剪候选角。
达到次数上限也不是成功；若线性求解失败，应报告失败而非继续使用无效增量。
此阶段是静态几何迭代，更新次数不是仿真时间，不调用 mj_step。

本人正确回答候选 q2=3.15 rad，超过 π，不能接受；20 次更新后误差仍为
0.0002 m 时应未成功停止。助手新增 [循环骨架](../examples/06_inverse_kinematics/iteration.py)，
复用单步 FK 和 Stage 4 的 Jacobian 公式，沿用本人已写的误差/增量表达式。
成功判断、任一关节越界判断、接受候选角三处由本人正确填写：
`error_norm < tolerance`、对上下界分别使用 `np.any`、以及 `q = q_candidate`。
提示：np.any 对布尔数组返回是否至少一项为真，np.all 返回是否全部为真；
