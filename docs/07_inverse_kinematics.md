# Key Concepts

FK 输入关节角 q、输出位置 p=f(q)；位置 IK 给定目标 p_target，寻找合适的 q。
位置误差 e=p_target-f(q)，目标与当前位置都用世界 xy 坐标、单位 m。
利用当前姿态的 J 求解 J*δq=e，得到完整的局部线性修正 δq（rad），
再按 q_new=q+α*δq 更新，其中 α 为无量纲步长比例，本课取 0.5。
α 不是物理时间步长，δq 不是力矩。新 q 是候选姿态，不表示机器人瞬间物理运动到那里。
本例使用可逆 2×2 J，直接解两条线性方程；不把这个方法泛化为所有 Jacobian 都可逆。

Jacobian 只作局部近似：必须用 FK 重算新位置和误差，不能仅凭 J*δq=e 宣称到达。
较小 α 缩短单次修正，但不保证任意情况下收敛。接近奇异时须注意增量可能很大。
成功停止：新位置误差的欧氏长度 ||e|| 小于选定容差（本课 ε_pos=1e-4 m，即 0.1 mm）。
迭代次数上限是终止保护，不是成功条件；后续 S5.3/S5.4 才实现循环、关节限制和失败测试。
来源：[Modern Robotics 数值 IK](https://modernrobotics.northwestern.edu/nu-gm-book-resource/6-2-numerical-inverse-kinematics-part-1-of-2/)。
