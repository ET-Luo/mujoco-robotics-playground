# Key Concepts

MuJoCo 的 `geom` 提供碰撞形状。接触是两个可碰撞 geom 在当前状态下满足接触条件时，
由碰撞检测生成的数据，不会新增 body、joint 或 actuator。

拟创建水平 plane 和半径 0.05 m 的自由球体。球心初始世界高度为 0.20 m，
球体最低点为 0.15 m，高于 z=0 的地面。重力使球体下落；球心接近 0.05 m 时，
球面最低点接近地面，预计开始产生接触。

`data.ncon` 是当前状态的接触数量。每次 `mj_step(model,data)` 推进时间并更新状态、
运动学、碰撞和接触；接触可通过 `data.contact[i]` 读取。`geom1`/`geom2` 是两个
geom 的整数 ID，可用 `mj_id2name` 转为名称；`pos` 是世界坐标系接触位置，单位 m。
接触数量和顺序可随状态变化，不应假定某对 geom 永远是 contact[0]。

### 后续完整组合任务清单

1. Reset：恢复机器人、夹爪、物体与目标的已知初态，清零速度并刷新派生量。
2. Reach：移动到预抓取位姿，检查世界系位置/必要朝向容差，超时则失败。
3. Align：确认物体位于两指之间且预计闭合路径无碰撞。
4. Close：缓慢闭爪，记录左右手指—物体接触，而不是只检查 ctrl。
5. Grasp check：保持一段时间，检查物体相对夹爪位姿和滑移；双侧瞬时接触不够。
6. Lift：小幅抬升，检查物体世界高度增加和相对夹爪滑移。
7. Transfer：移动到放置点上方，限制速度并持续监测是否掉落。
8. Descend：缓慢下降，直到真实 object-ground 支撑接触出现。
9. Release：确认支撑后张爪，检查两指与物体接触消失。
10. Retreat：夹爪撤离，避免再次碰动物体。
11. Final check：检查目标位置/姿态、ground 支撑、无手指接触和低速度；分别报告成功、
    超时、掉落、错位或仍在运动，不能用单一“运行结束”代替结果。

该清单是后续组合实验的阶段边界，不表示已实现完整 pick-and-place 状态机或路径规划。
