# Key Concepts

关节目标描述各关节应取的角度，例如 q_target，形状随关节数而定，转动关节单位 rad。
末端位置目标描述 site 在某参考系中的位置，例如世界系 p_target=(x,y,z)，形状 (3,)，单位 m。
两者不是同一种量：不能把“世界 +x 移动 0.01 m”直接写入以 rad 为目标的关节执行器 ctrl。

本阶段采用位置任务、世界坐标系。当前世界位置 p_W 与目标 p_target,W 相减得到
e_W=p_target,W-p_W，形状 (3,)、单位 m。位置 Jacobian Jp,W 的形状为 (3,nv)，
单位对转动自由度为 m/rad，满足局部关系 delta_p_W ≈ Jp,W*delta_q。
因此映射的输入是世界系位置修正，输出是关节增量 delta_q（rad）；后续 S6.2 才加入
增量限制并做单步验证。这里的 delta_q 仍是几何命令，不是力矩或经过的物理时间。

UR5e 示例的 ctrl 是关节位置伺服目标，单位为 rad。若后续要驱动物理模型，必须把
笛卡尔目标经过 Jacobian 映射为受限的关节目标，再由执行器作用；不能直接混用单位。
